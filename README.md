 ## My Thoughts
The article above is a research experiment Anthropic conducts on software engineers to see the effect of AI assistance on their coding skills and understanding. All the participants had to complete a coding task using an unfamiliar Python package, and next had to take a quiz on the coding concepts they just used. As expected, there was an overall decrease in quiz score when engineers relied on AI assistance. However, what I found interesting was that some participants asked the AI to generate the code, but also asked follow up questions to improve their understanding, and others only asked conceptual questions to help them complete the task.
